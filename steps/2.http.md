# Step 2: Implement Handler Bodies

## Target: implement the three handler bodies

Add the missing imports (`bson`, `domain`) and replace each stub:

### Create — parse `{ "title": "..." }`, return 201

```go
func (h *Handler) Create(c *fiber.Ctx) error {
	var body struct {
		Title string `json:"title"`
	}
	if err := c.BodyParser(&body); err != nil {
		return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": err.Error()})
	}
	result := h.useCase.CreateTask(c.Context(), body.Title)
	if result.IsError() {
		return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": result.Error().Error()})
	}
	return c.Status(fiber.StatusCreated).JSON(result.MustGet())
}
```

### ChangeStatus — parse `:id` as ObjectID, parse `{ "status": "..." }`

```go
func (h *Handler) ChangeStatus(c *fiber.Ctx) error {
	id, err := bson.ObjectIDFromHex(c.Params("id"))
	if err != nil {
		return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": "invalid id"})
	}
	var body struct {
		Status domain.Status `json:"status"`
	}
	if err := c.BodyParser(&body); err != nil {
		return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": err.Error()})
	}
	result := h.useCase.ChangeStatus(c.Context(), id, body.Status)
	if result.IsError() {
		return c.Status(fiber.StatusBadRequest).JSON(fiber.Map{"error": result.Error().Error()})
	}
	return c.JSON(result.MustGet())
}
```

## Key rules

- Handler depends on `port.UseCase` only — never on `*application.Service`
- Errors always return `{ "error": "message" }` as JSON
- Check `.IsError()` before calling `.MustGet()`
- Valid status values: `pending`, `in_progress`, `done`
