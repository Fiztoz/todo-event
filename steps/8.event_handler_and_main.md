# Step 8: Save Handler + Wire Main

Create `domain/task/adapter/event_handler.go` and update `cmd/api/main.go`.

The save handler is the only place that calls `repo.Save`. It reacts to domain events published by the service.

## Target: `domain/task/adapter/event_handler.go`

```go
package adapter

import (
	"context"

	"todoe/domain/task/domain"
	"todoe/domain/task/port"
	"todoe/internal/event"
)

func NewSaveHandler(repo port.Repository) event.HandlerFunc {
	return func(ctx context.Context, e event.Event) error {
		task, ok := e.Payload.(domain.Task)
		if !ok {
			return nil
		}
		return repo.Save(ctx, task).Error()
	}
}
```

## Target: `cmd/api/main.go` — wire bus, handler, service

Add imports:

```go
taskdomain "todoe/domain/task/domain"
"todoe/internal/event"
```

Replace the task wiring block:

```go
taskRepo := taskadapter.NewMongoRepository(clientIO)

bus := event.NewEventBus()
saveHandler := taskadapter.NewSaveHandler(taskRepo)
bus.Subscribe(taskdomain.EventCreated, saveHandler)
bus.Subscribe(taskdomain.EventStatusChanged, saveHandler)

taskService := taskapplication.NewService(taskRepo, bus)
taskHandler := taskhttp.NewHandler(taskService)
```

## Key rules

- Handler lives in `adapter/` — it touches infrastructure (`repo.Save`)
- `e.Payload.(domain.Task)` — type-assert the payload; return nil if it doesn't match
- `repo.Save(...).Error()` — returns nil on success, error on failure
- Adding a new side effect = new handler + `bus.Subscribe` — service and existing handlers do not change

## Check it compiles

```bash

```

## Flow summary

```
POST /tasks
  → handler.Create
  → service.CreateTask
      → domain.NewTask        (pure)
      → publisher.Publish     (EventCreated)
          → SaveHandler       → repo.Save → MongoDB
  ← task returned to caller
```
