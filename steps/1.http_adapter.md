# Step 1: HTTP Adapter

Implement the three handler bodies in `domain/task/adapter/http/handler.go`.

The file already exists with the struct, constructor, and stub methods. Routes are registered in `cmd/api/main.go`.

| Handler | Route | Use case method |
|---|---|---|
| `Create` | `POST /tasks` | `CreateTask` |
| `List` | `GET /tasks` | `ListTasks` |
| `ChangeStatus` | `PATCH /tasks/:id/status` | `ChangeStatus` |

## Starting point: `domain/task/adapter/http/handler.go`

```go
package httpadapter

import (
	"github.com/gofiber/fiber/v2"

	"todoe/domain/task/port"
)

type Handler struct {
	useCase port.UseCase
}

func NewHandler(useCase port.UseCase) *Handler {
	return &Handler{useCase: useCase}
}

func (h *Handler) Create(c *fiber.Ctx) error {
	return c.SendString("create task")
}

func (h *Handler) List(c *fiber.Ctx) error {
	return c.SendString("list tasks")
}

func (h *Handler) ChangeStatus(c *fiber.Ctx) error {
	return c.SendString("change status")
}
```
