# Step 5: Update Port — Add Publisher Interface

Add the `Publisher` interface to `domain/task/port/port.go`.

The service will depend on this interface to publish domain events without knowing about the event bus implementation.

## Starting point: `domain/task/port/port.go`

```go
package port

import (
	"context"

	"github.com/samber/mo"
	"go.mongodb.org/mongo-driver/v2/bson"
	"todoe/domain/task/domain"
)

type UseCase interface {
	CreateTask(ctx context.Context, title string) mo.Result[domain.Task]
	ListTasks(ctx context.Context) mo.Result[[]domain.Task]
	ChangeStatus(ctx context.Context, id bson.ObjectID, status domain.Status) mo.Result[domain.Task]
}

type Repository interface {
	Save(ctx context.Context, task domain.Task) mo.Result[struct{}]
	FindAll(ctx context.Context) mo.Result[[]domain.Task]
	FindByID(ctx context.Context, id bson.ObjectID) mo.Result[domain.Task]
}
```

## Target: add `Publisher` and import `internal/event`

```go
package port

import (
	"context"

	"github.com/samber/mo"
	"go.mongodb.org/mongo-driver/v2/bson"

	"todoe/domain/task/domain"
	"todoe/internal/event"
)

type UseCase interface {
	CreateTask(ctx context.Context, title string) mo.Result[domain.Task]
	ListTasks(ctx context.Context) mo.Result[[]domain.Task]
	ChangeStatus(ctx context.Context, id bson.ObjectID, status domain.Status) mo.Result[domain.Task]
}

type Repository interface {
	Save(ctx context.Context, task domain.Task) mo.Result[struct{}]
	FindAll(ctx context.Context) mo.Result[[]domain.Task]
	FindByID(ctx context.Context, id bson.ObjectID) mo.Result[domain.Task]
}

type Publisher interface {
	Publish(ctx context.Context, e event.Event)
}
```

## Key rules

- `port/` contains interfaces only — no structs, no framework imports
- `Publisher` mirrors the `event.Publisher` interface — the service depends on this port-level abstraction, not on `*event.EventBus` directly
